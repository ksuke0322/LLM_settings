# 進捗記録の形式

これは記録形式であり、ファイル作成・ゲーム操作の承認ではない。保存先と書き込み権限を確認し、承認済みの場所だけ更新する。権限がなければ現在のチャットに必要な進捗を報告する。

## 実行単位

- 確認日時・タイムゾーン、対象アカウントの区別に必要な最小情報（秘密情報を含めない）
- 依頼された開始地点・終了範囲、進行順、別ステージの扱い
- 現在の画面、確認できたAP・青輝石の残高
- ステージ別の進捗、次の正確な開始地点、停止理由

## ステージ単位

| 項目 | 記録する値 |
|---|---|
| ステージ | Normal／Hard、章、番号、現在のモード |
| 開始前の状態 | 星数、未達条件、対象報酬ごとの回収状態、確認日時 |
| 攻略情報 | 参照URL、確認日、現在の画面との差、採用経路と編成方針 |
| 編成 | 生徒名、役割、確認した攻撃タイプなど。部隊番号だけで済ませない |
| 経路 | 配置・移動・戦闘・箱・ボスの順と期待するターン／Sランク数。該当なしも明示 |
| 挑戦 | 通算1〜3回、開始・結果、リスタート理由、実測時間・撤退、次に変える点 |
| 資源 | 確認できた開始前後のAP、消費・返還、青輝石残高。未観測は未確認 |
| 完了証拠 | 結果画面、ステージの星、各条件、報酬の種類と量、必要なら章の総星数 |
| 状態 | 未着手／進行中／完了／未達／未確認。勝利と完了を分ける |

## 記録上の注意

- 初回を含めた挑戦数を増分で残す。リスタートや日をまたいだ再開でも同一ステージの通算を失わない。
- 箱・初回・★3・チャレンジなどの報酬は別々に「回収済み／未回収／未確認／該当なし」を持つ。残高差だけで内訳を推測しない。
- 未確認、表示なし、取得失敗を0や完了に置き換えない。後から確認できた場合は、確認日時と根拠を添えて更新する。
- 過去の報告と実際の操作履歴で試行回数などが食い違う場合は、根拠を照合して訂正する。短い要約を無条件に正本にしない。
- 座標、画面サイズ依存の位置、過去のAPや部隊を次回の既定値にしない。
- 再開時は保存記録と実画面を照合する。完了した任務の重複実行、別アカウントへの記録流用を防ぐ。
