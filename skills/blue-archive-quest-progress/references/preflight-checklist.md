# 毎ステージ開始前の確認表

このファイルを毎ステージの開始前に見返す。前ステージの結果や保存部隊をそのまま信用せず、現在の画面に対して確認する。

| 確認対象 | 確認する内容 |
|---|---|
| 依頼範囲と順序 | Normal／Hard、章、番号、開始地点と次の対象が一致しているか。A・Bなどの扱いは指示済みか |
| 現在の進捗 | ★の数、未達条件、対象報酬の未回収・回収済み・未確認を区別できているか |
| 攻略情報 | 正しいNormal／Hard・番号の情報か。現在の画面と同じモードか。参照URLと採用する方針を確認したか |
| ゲーム上の条件 | 時間、撤退、Sランク数、ターン数、戦闘数、箱やチャレンジなど、実際に存在する全条件を読んだか |
| 編成 | 敵装甲と生徒の攻撃タイプが合うか。タンク・回復・範囲／単体火力・支援は足りるか。所持・育成状態を確認したか |
| 配置と経路 | 各部隊の初期位置、移動順、交換・ワープ等の仕組み、必要戦闘数、最終ターン、箱とボスの到達順を計画したか。マップのないモードなら該当なしとしたか |
| 資源と回数 | APと必要消費量、残り挑戦枠が足りるか。今回が同一ステージの何回目か。リスタート時の消費は確認できているか |
| 検証方法 | クリア後に何を見れば★3・回収完了と分かるか。報酬の受け取り操作が別にあるか |

開始できる条件が揃ったら実行する。表示・攻略情報・記録が食い違う場合は解消してから資源を消費する。準備完了の報告だけで止まらず、承認された攻略を続ける。

戦闘開始後はAUTO ONと黄色の三重矢印を確認する。クリア前は、戦闘外の情報から目標未達が確定していないかを確認する。

## クリア直後・次へ進む前

1. 結果の時間、撤退、その他の条件を確認する。演出だけで判断しない。
2. ステージ詳細で★3と未達条件の有無を確認する。
3. 対象報酬を受け取り、種類と量を確認する。確認不能は未確認のまま残す。
4. 必要な進捗記録を更新し、残APと次の正確なステージを確定する。
5. 章の切替では、対象全ステージの星と章の総星数を照合する。次章開放やComplete表示だけで進まない。
