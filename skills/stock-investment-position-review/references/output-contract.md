# Position Review Output Contract

## Compact

- 単一銘柄:
  - `対象企業 / 銘柄コード / 状態 / 保有判断 / 追加投資判断`
  - `review_profile`
  - `最新終値 / 平均取得単価 / 損益率`
  - `利確・縮小目安 / 撤退・防衛目安 / 追加条件`
  - `リスク警告`
- 複数銘柄:
  - 各銘柄 1 行サマリー
  - `保有判断サマリー`
  - `追加投資サマリー`
  - `取得失敗`

## State / Sidecar

- 長い保有継続理由、R倍数文脈、drawdown 補足は state / sidecar を優先する
- `compact` では行動判断に必要な要約だけを返す
