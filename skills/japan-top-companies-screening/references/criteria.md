# Screening Criteria

短中期向けの日本株候補を東証33業種で洗い出すときの既定基準。

## 基本フィルタ

- `時価総額`: 業種内で上位5〜10社を優先する
- `売買代金`: 直近3か月平均で十分に厚い銘柄を優先する
- `ROE`: 8〜10%以上を目安にする
- `営業利益率`: 業種中央値以上を基本にする
- `自己資本比率`: 40%以上を目安にする
- `営業CF`: 3期連続プラスを優先する
- `フリーCF`: 安定してプラスなら加点する
- `PER` `PBR`: 業種比で極端に割高なものは除外候補にする

## 優先順位

1. 時価総額
2. 売買代金
3. 財務安全性
4. 収益力
5. 成長性
6. 割高すぎないこと
7. 業界内地位

## 定性補正

- 国内シェア上位
- 世界シェア上位
- ブランド力
- 価格決定力
- 参入障壁
- 海外競争力

## 除外候補

- 直近で赤字転落した
- 営業CF が継続的に弱い
- 有利子負債の重さが目立つ
- 不祥事や会計問題などで平常比較が難しい
- 流動性が低く、短中期売買に不向き

## 業種特性の扱い

- 銀行、保険、証券は `自己資本比率` や `営業利益率` の横並び比較をそのまま使わず、業種内相対評価を優先する
- 商社、資源、海運は市況依存が強いので、利益の質と還元方針を重視する
- 製薬はパイプライン、特許、主力薬依存を注記する
- 電機、自動車、機械は海外売上比率と為替耐性を確認する

## Macro Overlay

- `risk_on`: 景気敏感、大型半導体、機械、自動車の相対優位を確認する
- `risk_off`: ディフェンシブ、キャッシュ創出力、財務安定性の比重を上げる
- `円安 / 円高`: 外需・内需の向きがどう変わるかを確認する
- `金利上昇 / 低下`: 金融、不動産、高バリュエーション成長株の優先度変化を見る
- `資源高 / 資源安`: 商社、資源、物流、素材の監視価値を補正する

## Sector Relative Strength

- 業種指数または代表銘柄で、TOPIX 比の強弱を見る
- 同業比較では「絶対に良い会社」より「今その業種で相対優位か」を優先する
- policy やテーマで資金が回っている業種は `sector_cycle` に残す

## Execution Feasibility

- large-cap でも寄り付きギャップ主導なら `execution_caution` を残す
- 1日売買代金が厚くても、イベント集中で監視価値が薄い銘柄は priority を落とす
- `liquidity_tier` は `top_tier` `adequate` `thin_for_large_size` のように粗く分類する

## 出力の粒度

- 全33業種では各業種 `1〜3社`
- 必要なら `本命` `次点` `監視候補` に分ける
- 抽出理由は `定量` と `定性` を分けて書く
- regime 補足は `macro_sensitivity` `sector_cycle` `regime_fit` に圧縮する

## Daily Monitoring

### 2層構造

1. `母集団`: 東証33業種から各1社を基本に `33社前後`
2. `重点監視`: 毎日追う候補として `10〜15社`

### 重点監視へ圧縮する基準

- `売買代金`: 十分に厚く、毎日の出入りがしやすい
- `相対強さ`: 業種内または大型株内で強さが見える
- `決算距離`: 決算直前すぎず、監視の意味がある
- `テーマ性`: 市場テーマ、政策、需給、物色の流れに乗りやすい
- `継続監視価値`: 一度見れば終わりではなく、数日から数週間追う意味がある
- `regime_fit`: 今の地合いで監視優先度を維持できる

### 前回監視銘柄の残留判定

- `継続`: 選定理由だった `流動性` `財務安全性` `業界地位` `監視テーマ` が概ね維持されている
- `除外`: 決算悪化、財務悪化、テーマ剥落、相対優位低下が明確
- `保留`: 企業の質は高いが、短中期の監視優先度が落ちている

### 継続判定で見るポイント

- `定量変化`: ROE、営業利益率、自己資本、営業CF、還元方針、ガイダンス修正
- `定性変化`: 業界内ポジション、テーマ性、政策追い風、需給、イベント通過後の監視価値
- `相対比較`: 同業または大型株内で、今その銘柄を残す合理性がまだ強いか
- `regime 変化`: 会社の質は高くても current regime で追う意味が薄れていないか

### 入れ替えルール

- まず前回銘柄の `継続` を優先する
- `除外` や `保留` で空いた枠だけ、新規候補で埋める
- 新規追加は、前回銘柄より `今見る意味` が強い場合に限る
- 毎回の大幅入れ替えは避け、差し替え理由を明示する

### daily 監視で落とす候補

- 流動性はあるが値動きが鈍すぎる
- 長期では優良でも短中期では材料が乏しい
- 決算やイベント直前でリスクが高すぎる
- 同じテーマの類似銘柄が多く、優先順位が低い
- 前回は採用したが、継続する根拠より除外する根拠の方が強くなった
- regime と逆風が続き、短中期の監視価値が低い

### 最終出力

- `重点監視` テーブルを出す
- 継続レビュー時は `前回監視銘柄レビュー` と `新規追加候補` を先に出す
- 最後に `重点監視銘柄名:` を置き、企業名だけをカンマ区切りで1行出す
