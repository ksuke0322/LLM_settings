# UI遷移プレイブック

このプレイブックを、モンスト素材周回のUI操作、操作パラメータ、状態遷移の唯一の正本とする。

## 実行前の経路確認

AGENTS.md の指示を常に優先する。このプレイブックは、AGENTS.md の承認、開始、停止の条件を緩和しない。

2026-10-18のセッションmetadataには cua_repl.js が掲載されているが、実機画面の取得とドラッグ操作は未確認である。旧 node_repl と @oai/sky、および computer-use:computer-use は external-unknown とし、利用可能とも非存在とも断定しない。

このmetadataはその時点のスナップショットであり、実行時の利用可否を示さない。実行ごとに最新の正式なツール説明と利用可能な経路を確認し、画像取得、単一操作、操作後の再取得を明記した経路を一つだけ選ぶ。

正式な説明で経路と必要能力を確認し、接続などの非変更確認を先に行う。能力確認のためだけにゲームを操作してはならない。ユーザーがゲーム操作を明示的に依頼した場合は、状態表に従う安全な最初の操作を行い、直後に画面を再取得して能力と遷移を確認する。

正式な説明で確認できないメソッドを推測してはならない。選定経路で接続または必要能力を確認できない場合は、旧経路へ黙って切り替えず、blocked として報告する。

## 操作パラメータ

| 項目 | 値 |
|---|---|
| 画像更新 | UI操作の直前に最新画像を取得し、操作後にも最新状態を再取得する |
| 操作単位 | 画像確認とUI操作1回をひと組として扱う |
| 共通進展期限 | 同じ状態に初めて入ってから5分（300,000 ms）。期待する遷移や進展がなければ停止し、同じ状態の再取得、再操作、待機ではリセットしない。SPECIAL_REWARDも初回入場を起点に同じ期限を適用する |
| 報酬候補 | 空欄候補から1箇所だけ選ぶ |
| 進展なし補正 | 最新画面を再分析してから最大2回まで |
| HINTフォールバック | 最新画像で対象を確認してから1回まで |
| 演出待ち | 操作せず最大15秒を目安に待ってから再取得する |
| 接続再取得 | 接続が切れた場合の画面再取得は1回だけ |

## 共通の判断規則

- 各操作の対象は、その操作の直前に取得した最新画像で確認する。
- 画面遷移後は、以前の座標や要素番号を使わない。操作対象は現在の画像で選び直す。
- 同じ座標の連打や、画面にない対象の推測操作をしない。
- 演出中は操作せず、パラメータ表の待機後に画面を再取得する。画面を判別できなければ停止する。
- 対象クエスト、ソロ状態、デッキ番号は画面で確認する。異なるクエストを推測して選ばない。
- 追加リソースの消費、課金、マルチ参加、別クエストの推測が必要になった場合は、直ちに操作を止める。

## 状態表

状態表の「操作」欄に書いた内容だけを行い、操作ごとにパラメータ表どおり画像を更新する。

| 状態 | 入力 | 操作 | 期待状態 | 再取得 | 停止条件 |
|---|---|---|---|---|---|
| HOME | 最新画像にHOMEとSHORT CUTが見える | 表示中のSHORT CUTをタップする | DECK_SELECT | 操作後に最新画像を取得する | HOMEまたはSHORT CUTを確認できない。共通進展期限内に期待状態へ進まない |
| DECK_SELECT | クエスト名、ソロ状態、デッキ番号が最新画像で確認できる | 指定条件と一致するときだけ、表示中の出発をタップする | BATTLE | 操作後に最新画像を取得する | クエスト、ソロ状態、デッキを確認できないか不一致。マルチ参加画面が表示された。共通進展期限内に期待状態へ進まない |
| BATTLE | 最新画像のターン表示、操作キャラ、敵配置 | 現在の画像だけを見てドラッグする。固定リプレイや属性別の未確認手順を使わない | 敵撃破、ターン更新、次バトルなどの進展、またはBATTLE継続 | ドラッグ後に最新画像を取得し、進展を確認する | 進展がなければ最新画像を再分析し、補正上限に達したら停止する。共通進展期限内に進展しない場合も停止する。攻略困難、全滅の可能性、画面異常も停止 |
| HINT | 最新画像に攻略ヒントと操作対象が見える | オレンジ色のOKを優先する。変化がなければ最新画像を取り直し、青い確認が見える場合だけパラメータ表の上限内でフォールバック操作を行う | CLEAR_INFO | OKとフォールバックの各操作後に最新画像を取得する | 対象を確認できない。追加消費や課金を求められる。想定外の画面へ進む。共通進展期限内に期待状態へ進まない |
| CLEAR_INFO | 最新画像にクリア情報と終了ボタンが見える | 表示中の終了をタップする | SPECIAL_REWARD | 操作後に最新画像を取得する | 終了ボタンを確認できないか、別の画面へ進む。共通進展期限内に期待状態へ進まない |
| SPECIAL_REWARD | 報酬画面へ最初に入った時刻と最新画像。宝箱、報酬アイコン、画面外、タップ済みの位置を識別できる | それらを避けた現在の空欄候補を選んでタップする | RESULTの報酬画面 | タップ後に最新画像を取得する。遷移しなければ候補を最新画像から作り直す | 共通進展期限に達した。画面が不明。追加消費や課金が必要。成功判定前にRESULTのOKを押さない |
| RESULT | 最新画像にクリア報酬とオレンジ色のOKが見える | 表示中のOKをタップする | HOME_CHECK | 操作後に最新画像を取得する | OKを確認できないか、追加消費を求められる。共通進展期限内に期待状態へ進まない |
| HOME_CHECK | 最新画像にHOME、対象クエスト、現在スタミナ、次の周回に必要なスタミナが見える | 画面情報を読み取る。タップはしない | スタミナ不足ならcompleted。足りていればHOMEから次の周回へ進む | HOME_CHECKに入った時点の画像で確認する | HOMEまたは必要な値を確認できない。スタミナ回復や追加消費が必要 |
| stopped | 想定外の画面、安全条件への抵触、ユーザーの停止指示 | UI操作を行わない | stoppedとして報告する | 追加の画面取得を行わない | 理由と最後に確認できた状態を記録して終了する |
| blocked | 正式なツール説明、実機接続、画像取得、操作能力のいずれかを確認できない | ゲーム操作を行わない | blockedとして報告する | 接続確認の再試行はパラメータ表の範囲内に限る | 代替経路を推測して使わず、未確認事項を記録して終了する |

## 状態の扱い

画面が状態表のいずれにも一致しない場合は stopped とする。

HOME_CHECKで必要なスタミナが不足していれば、stoppedではなくcompletedとして正常終了する。

SPECIAL_REWARDの期限は初回入場から連続して進む。画面再取得、演出待ち、候補の作り直しではリセットしない。期限内でも画面が不明になった場合や追加消費が必要になった場合は、ただちに stopped とする。

HINTのフォールバックを含む各操作は、操作直前に取得した最新画像で対象を確認してから行う。確認できない対象を推測して押さない。
