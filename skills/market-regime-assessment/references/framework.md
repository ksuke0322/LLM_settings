# Market Regime Framework

## Core Axes

- 指数方向: TOPIX / 日経平均 / グロース市場
- 業種 leadership: 半導体、金融、内需、外需、ディフェンシブ
- 為替: USD/JPY
- 金利: 日本金利、米金利
- 商品市況: 原油、銅など

## Common Interpretations

- `risk_on`
  - 景気敏感、半導体、グロース、high-beta に資金が向かいやすい
- `risk_off`
  - ディフェンシブ、大型主力、キャッシュ創出力が重視されやすい
- `neutral`
  - 一部テーマや業種だけ selective に強い

## Bucket Preference

- `large_cap favored`
  - 金利テーマ、為替テーマ、指数寄与の強い日
- `high_beta favored`
  - グロースやテーマ株に明確な資金流入が見える日
- `mixed`
  - large-cap と high-beta が併存するが、entry quality の見極めが重要

## Output Discipline

- 個別銘柄の売買指示はしない
- favored / avoid は bucket 単位に留める
- execution caution を必ず 1 行添える
