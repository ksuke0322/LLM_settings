## 実行ルール

- 2026-10-18の開始指示で#21から再開。新たな判断は保留理由を記録してskipし、一覧順に1件ずつ進める。

- 一度に1件。調査・実装・テスト追加はgpt-6-luna/maxへ小さく委任（対象1つ、問い3つ以内、12分以内）。委任中のworktreeは更新しない。
- 親は分解・最終判断・ミューテーション・PR・merge commitでのマージ・記録を担当。
- 関連検証から全件検証へ進む。main checkoutではテストしない。1タスク1PR。
- 非Archify変更だけは、同条件の現行main参照と候補の全件実行で非Archify通過、Archifyの失敗名・原因・スキップ一致、新規悪化なしを記録して既知失敗を例外扱いする。Archify本体・共有資産・テスト基盤の変更には適用しない。
- mainへのマージ後、内容保全とcleanを確認した完了worktreeは通常削除する。未マージ・dirty・不明は保全する。
- 新たな判断は保留理由と再開条件を記録してskipし、次へ進む。既決方針は再承認を求めない。削除・強制push・履歴改変は通常後片付けの既承認範囲を除き個別承認。
- 1件終了ごとに、このリストとHTMLを実際の時刻で更新しmainへ反映してから次へ進む。
