- `skills/task-flow-non-speckit/SKILL.md` の適用範囲は既存の `specs/flow` 内に維持した。全repoの新たな状態基盤は導入していない。

- タスク完了（旧doneの成果受入れ）とGit反映、PR、cleanup、最終lifecycleを別に記録する。未解決の失敗等から直接完了にしない。
- 必須の外部業務書込が未実施なら承認待ちまたはblocked。承認後に実行・検証へ戻す。成果受入れ済みでもPR未マージなら最終未完了とする。
- 方針了承と開始を分離する。ユーザー停止後は明示再開が必要、それ以外の依存解消・修正は既承認範囲内で再開できる。

- PRなし・リモートなしの経路は通常削除の既承認例外に広げない。個別承認と証跡が揃うまでは保全・削除停止・最終未完了とする。今回はremote/PRのある通常経路である。
